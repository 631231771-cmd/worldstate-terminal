# WorldState v0.7 — Live Data Activation & Global Macro

Updated: 2026-08-10

## What is active

v0.7 keeps WorldState as a local-first macro research terminal and activates a
small, auditable public-data path. It does not claim complete global coverage,
real-time market data, or causal prediction.

- Product and API version: `0.7.0`
- Analysis methodology: `macro-event-engine-v0.7-live-global`
- Database head: `0010_operational_state_defaults`
- API additions: `/v2/data/sync/public`, `/v2/data/bootstrap-free`,
  `/v2/data/freshness`, `/v2/macro-systems`, `/v2/world-state/history`, and
  `/v2/watchlist`, `/v2/market-bars/import-context`,
  `/v2/data/macro-series/import-official-csv`, and
  `/v2/releases/{release_id}/consensus/import-csv`
- UI addition: Data Control Center (`数据控制中心`)

## Public providers

The public adapters are transport adapters owned by WorldState. They normalize
official CSV/SDMX responses into `Series` and `Observation` rows with source
artifacts and quality records. They never insert fixture rows when a request
fails.

## Freshness and provenance

`/v2/data/freshness` reports retrieval age and observation-period age. A recent
HTTP fetch cannot hide an old monthly or quarterly observation: status becomes
`STALE` when the covered period exceeds the configured freshness threshold.
Each public observation is marked `data_mode=observed`, records its retrieval
time, source hash, source artifact and quality grade, and explicitly declares
that point-in-time vintage semantics are not available for these adapters.

Provider bundles are series-granular. If one official series is empty or
temporarily unavailable, valid sibling series are retained and the provider
run returns `partial` with a `series_failures` map. If no series succeeds, the
run is `blocked`.

## Global macro layer

`/v2/global-macro` compares available observed series across the configured
country/entity catalog. It returns scores, direction, momentum, coverage,
freshness, drivers, missing dimensions and divergence descriptions. It does
not fill missing US, Japan or China data with proxies or fixtures.

`/v2/macro-systems` exposes transparent component cards for liquidity, rates,
dollar and energy/credit. A card can be `available`, `partial`,
`unavailable`, or `framework`; component availability is visible in the UI.
The current public-only runtime now shows all four configured macro-system
cards with observed components: global liquidity 4/4, dollar system 4/4, rates
5/5 and energy/commodities 3/3. This is daily/current-state coverage, not a
claim of tick, cash-market or historical first-print completeness.

The Data Control Center also accepts an official macro CSV. Required columns
are `canonical_key`, `period_start`, `value` and `entity_iso3`; optional
`vintage_date` and `available_at` columns enable an explicitly labelled manual
PIT snapshot. The import stores the raw source artifact, quality record and
manual/verification flags. Without those columns it remains an ingestion-time
proxy and cannot be used for PIT backtests.

## Operational state

Migration `0009_operational_state` adds immutable daily `WorldStateSnapshot`
rows and a small user-owned `WatchlistItem` table. Snapshot and watchlist
endpoints preserve the requested data mode and methodology; they do not alter
the underlying observation vintages.

The scheduler includes a daily public-macro sync job and an idempotent daily
world-state snapshot job. It is non-blocking and reports `completed`, `partial`
or `blocked`. The command-line equivalent is:

```powershell
 .\WorldState.bat sync-public --start-date 2026-08-01 --end-date 2026-08-09 --providers fred,ecb,boe
```

- United Kingdom: growth, inflation and policy dimensions are partial.

These additions are not claimed as official national direct-import pipelines.
They are FRED current-public graph histories whose underlying publishers
include OECD, BIS, Eurostat and the BOJ. They are non-PIT, unsuitable for
historical first-print reconstruction and ineligible for minute event research.
The separate official BOJ/China import boundaries remain available for a future
source-linked export.

The runtime after synchronization contains 129,547 observed macro storage rows
across 64 populated series and 20,026 observed daily/context market bars across
eight instruments. Repeated current-public retrievals create multiple local
capture rows for some periods; the state engine now resolves one latest-known
row per period at the requested `as_of`, so retrieval vintages cannot inflate
history. Freshness uses the latest covered period, not a recent fetch time. The
runtime still contains zero observed consensus rows, zero observed intraday or

## Daily markets checkpoint (2026-08-11)

The observed runtime now contains 49,832 daily/context bars across 19 populated
instruments. It adds 3-month, 5-year and 30-year Treasury yields, the 10-year
real yield, Nasdaq-100, EUR/USD, USD/JPY, USD/CNY and U.S. high-yield spread to
the earlier eight-instrument board. All public FRED bars are current-public,
non-PIT context and are never eligible for event-minute analysis.

WorldState calculates 2s10s and 3m10y curve bars from matched observed Treasury
input dates. The 5,802 derived rows use provider key `worldstate_derived` and
store both input bar IDs, input dataset keys, formula, calculation version and
calculation time. They are labelled derived in the product API/UI rather than
being presented as provider-native observations.

Market reads now partition history by provider, granularity, source symbol and
contract identity, and split at material time gaps. Only the newest compatible
segment supplies changes, sparkline and interactive chart points; older
segments remain disclosed in data details. A per-instrument bounded window
query and single-pass horizon calculation reduced the verified local
`/v2/product/markets` response from about 6.3 seconds to about 0.6 seconds.

The market drawer now uses TradingView Lightweight Charts 5.2.0 (Apache-2.0)
with 1W/1M/3M/1Y controls, crosshair, tooltip, resize support, dark styling and
visible attribution. It renders only real points in the active continuity
segment. The dependency and attribution obligation are recorded in
`THIRD_PARTY_NOTICES.md`.

## Country drill-down and durable navigation

The product Macro layer now preserves the global engine's real comparison and
divergence output and adds `/v2/product/macro/{country}`. A country projection
contains observed driver Series, related daily markets, recent/upcoming events
where the calendar actually applies, and a same-dimension comparison that
excludes missing scores.

Daily state history remains deliberately narrow. The runtime has one immutable
US World State snapshot. Other countries therefore show zero real history
points and an explicit limitation; the UI never backfills a visual trajectory
from current-version macro observations or from the US snapshot.

The rebuilt shell persists context in the URL and restores market, country,
dimension, Series, Event and Thesis selections after refresh. Ctrl+K resolves
those same entities through existing product/search APIs. Browser smoke at
1920x1080 verified China / Inflation, Gold, China CPI and an explicit FOMC
release without exposing provider IDs in the standard view.
