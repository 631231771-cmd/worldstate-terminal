# WorldState v0.7 beta closure

Updated 2026-08-11. This note records the event-correctness and desktop
boundary checkpoint; it does not claim that a live minute event is available.

## Event correctness

`event-intraday-v1` is the single persisted eligibility policy. A canonical
event-minute manifest must explicitly declare the policy version, `eligible`
status, matching `data_mode`, a positive row count and 60-second granularity.
Missing metadata is rejected. The same validator is used by market selection,
capability coverage, the event projection and the analysis readiness gate.

`AnalysisReadiness` matches Actual and consensus per canonical indicator. A
consensus snapshot is eligible only when its aware UTC `captured_at` is strictly
before the resolved release T0. T0 is stage-aware: FOMC uses the statement
stage; other releases use the release/decision stage. An observed run is
blocked with a structured response until release inputs, pre-T0 consensus and
eligible minute evidence are all present.

Minute import records key-window coverage (`pre_5m`, `post_1m`, `post_5m`,
`post_15m`, `post_30m`, `post_60m`). A missing bar makes that window
unavailable; it is not silently converted into a complete reaction. Proxy
Treasury futures are displayed as percentage-price changes, while cash yields
use basis points.

## Desktop boundary

`scripts/build-research-sidecar.ps1` builds a PyInstaller onedir artifact and
smokes it from a clean temporary install: fresh migrations, `/v2/health`, and
`/v2/product/{today,markets,macro,events}`. The smoke does not set
`WORLDSTATE_ROOT` or rely on the repository working directory. The Tauri
release resource layout can select this generated sidecar; development builds
continue to use the local Python environment. The current executable is not a
signed installer and the generated binary is not committed to source control.

## Runtime truth

The local runtime still has zero observed consensus snapshots and zero observed
minute bars. Therefore no observed CPI/NFP/FOMC event has a completed real
AnalysisRun. The bundled examples remain fixture-only demonstrations. The
first real event chain is operationally ready through CSV import, but remains
blocked until legal, traceable pre-T0 consensus and minute data are supplied.
