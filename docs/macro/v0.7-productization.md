# WorldState v0.7 Productization checkpoint

Updated: 2026-08-10

This checkpoint changes the default user experience without changing the
observed/fixture/PIT data model.

## Product surface

- Primary navigation is grouped into Overview, Markets, Macro, Events,
  Research and Advanced. Data Sources and Data & Methods remain available but
  are no longer presented as the main research path.
- Event selection is only shown on event-related pages. Today, Markets and
  World State no longer look like they are attached to a single release.
- Today is the default entry point. Its first screen prioritizes state,
  changes, market confirmation, upcoming releases and completed research.
- Learning Mode is an opt-in contextual layer. It shows the short learning
  chain on Today; it does not turn the terminal into a long course page.

## Progressive disclosure

Default cards answer What, Direction, Magnitude, Why it matters, Confidence
and Freshness. `Data details` disclosures expose provider, quality, source
limitations and other research metadata only when requested. Important states
such as stale, unavailable, manual and proxy remain visible as badges.

## Data Sources workflow

Data Control now uses forms and modal dialogs rather than `window.prompt`:

- FRED Key is saved only through the Tauri credential command;
- market context import uses a controlled asset list;
- official macro CSV import asks for provider label, source URL and verification
  before the file is submitted.

The API remains the stable `/v2` contract. The old `/v2/providers` fallback was
removed from the frontend; an unavailable `/v2/data/providers` response now
produces a user-safe error instead of silently showing legacy status data.

## Quality projection

Market dashboards and Daily Brief market confirmation resolve quality from the
persisted `DataQualityRecord`. Provider identity no longer implies a quality
grade. Missing quality records are shown as `UNKNOWN` with a limitation.

## Boundaries

This is productization, not a new data expansion milestone. No new event type,
provider family, news wall, map, automatic trading or v0.8 work is included.
The desktop build still uses the existing Python Research API sidecar boundary;
the UI must not imply a blank-computer self-contained installer.

## Validation

The checkpoint passed 181 backend tests, Ruff, strict mypy, the Terminal UI
production build, runtime API smoke checks, and GitHub Actions run
`31359986475` (Research API, Terminal UI and Windows desktop/Tauri jobs). PR
`#10` remains open as Draft.

## Terminal rebuild working checkpoint (2026-08-11)

The next v0.7 checkpoint keeps the same research and data-quality boundaries
while making the product projections the active source for the main terminal
workspaces:

- `/v2/product/today`, `/v2/product/markets`, `/v2/product/macro` and
  `/v2/product/events` are consumed by workspace-aware loading. Release detail
  is available at `/v2/product/events/{release_id}`.
- Market horizons are typed and unit-aware: rates are rendered in basis points;
  price-like assets remain percentage changes. This prevents the UI from
  applying a second scale to server-computed changes.
- Events are ordered by the server and prefer a recent completed,
  reproducibility-complete analysis. The event detail surface explicitly
  distinguishes actual, consensus, daily context and minute-reaction gaps.
- Public FRED graph CSV was synced for four additional observed series:
  China CPI (124 rows), China industrial production (107), Japan CPI (78) and
  Japan industrial production (111) in the local runtime. The FRED graph path
  is current-public, non-PIT and subject to covered-period staleness; it does
  not activate historical first-print or minute-event research.
- The local runtime currently has 62,340 observed macro observations, 20,017
  observed market bars, one observed world-state snapshot and zero observed
  consensus snapshots. Counts are runtime evidence, not fixture guarantees.

This remains a working checkpoint rather than a claim that global coverage or
minute event research is complete. PR #11 remains Draft.
