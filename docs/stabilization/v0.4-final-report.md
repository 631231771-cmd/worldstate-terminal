## Research-method corrections

- `surprise_z` is calculated only from at least 20 forecast errors strictly
  before T0 and non-zero historical variance. Threshold scaling has a separate
  field and UI label. Runs retain sample count, mean, standard deviation and
  cutoff time.
- NFP current surprises and revisions are transformed on each indicator's own
  declared scale before weighting. A revision-dominant classification requires
  genuine cross-indicator Z-scales; otherwise the changed indicators and the
  inability to compare dominance are disclosed.
- Historical matching reads the RegimeSnapshot linked to each AnalysisRun.
  Missing/missing regimes receive no match credit. The response lists used and
  missing dimensions and every contribution. High/unclean contamination is
  excluded and remaining contamination differences are scored.
- Fixed 30/15/5 sample thresholds suppress probabilities and percentiles below
  15 observations and prevent post-outcome filter expansion.

## Reproducibility and evidence

New AnalysisRuns retain release/value/consensus/stage identifiers, full OHLCV
bar snapshots, provider/source manifests, historical cohorts, algorithm/rule
versions, parameters and input/config/output hashes. The replay endpoint
recalculates each manifest hash from immutable stored data. Idempotency keys
reuse a completed run; failed orchestration is rolled back and recorded as a
separate failed run.

Evidence is persisted as individual EvidenceItems. Every confirmed fact binds
to its own Evidence ID. ResearchClaims require valid current-run IDs;
inferences require limitations and falsifiers; fixture/proxy use is disclosed;
unsupported, inconsistent or over-causal output falls back to deterministic
claims.

## Sessions and desktop boundary

`exchange-session-lite` handles US cash hours, DST, weekends, Good Friday,
selected early closes, CME-style Sunday/Friday boundaries and daily 17:00-18:00
ET maintenance. Instrument-specific next/fifth session endpoints and tradable
minute denominators replace natural elapsed-minute coverage. This remains an
experimental research calendar, not a complete licensed exchange calendar.

Tauri validates `/v2/health` product identity before adopting port 8000,
rejects a foreign listener, reports source/PID/port/provider diagnostics and
forwards both supported API secrets to migration and API children. The CI job
builds Terminal UI before Rust checks and an unsigned `--no-bundle` build.
