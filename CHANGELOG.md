# Changelog

## 0.3.0 — Macro Research Terminal migration

- Replaced World Monitor's news/map/geopolitical product surface with five
  macro-research workspaces.
- Introduced database v3, append-only release values and consensus snapshots.
- Added CPI, nonfarm-payroll and multi-stage FOMC demonstrations.
- Added event windows, reaction analysis, fixed historical matching,
  contamination controls and EvidencePack-constrained reports.
- Added FastAPI `/v2`, provider adapters, data-quality records and a Tauri
  desktop shell.
- Archived the former implementation at tag `world-monitor-legacy-freeze` and
  branch `archive/world-monitor-legacy`.
